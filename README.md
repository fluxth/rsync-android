# rsync-android

Automated build for musl-based rsync binary to run on Android via ADB.

## Download

Download binary from the [Releases](https://github.com/fluxth/rsync-android/releases) section.

## Acknowledgement

This repo is an automation of build steps from https://howtos.davidsebek.com/android-rsync-adb.html with modifications to enable some hashing/compression features.
